# ExitForge

**Keep the work. Recover the workflow.**

An authorized workspace export becomes a reviewed, editable offline application.
Meta Muse Spark Open via Baseten interprets workflow semantics; the source resolver
supplies complete explicit facts, a person confirms policy, and a shared engine
runs the work independently.

## Run

```sh
cd app
python -m exitforge.server --port 8766
```

Open http://127.0.0.1:8766. Python 3.12+; the saved-example/offline core needs no
third-party runtime package, provider key or account connection. Full instructions
and tests: [app/README.md](app/README.md).

The hosted new-input AI trial is exhausted. Two labeled saved actual Meta workflow
examples, manual review and downloads remain usable. No unlimited live AI access
is claimed. See the judge walkthrough for a complete reproducible experience.
