# Evidence and limitations

## Actual model and browser results

- November 3 delivery: one actual HTTPS Meta-via-Baseten request, HTTP 200,
  11.246 seconds; all four explicit relationships retained. Reviewed actions,
  exactly-one contextual task and actual downloaded app offline reload verified.
- November 3 editorial: one actual HTTPS request, HTTP 200, 23.773 seconds;
  all four explicit relationships retained. Amendment/revision then approval/
  release, one task and downloaded app offline reload verified.
- Those results are not a general accuracy or timing benchmark. They are two
  scoped synthetic cases. Earlier failures include unsupported task placeholders
  and omitted relations; the source-binding repair and typed validation address
  those observed classes without claiming universal reliability.
- The current built-in examples preserve actual raw semantic proposals and
  deterministic binding resolution. Ordered observation file hashes were checked.
- Eight portable/action modules match the earlier actual offline recording.
  The final edit labels prior offline footage and current hosted UI screenshots.

## Current verification

The final package manifest and its test logs identify fresh completed checks,
source hashes, media properties and remaining gaps. The source suite contains
82 Python and 36 JavaScript tests. A Windows loopback connection interruption was
observed in some local full-suite runs; isolated server checks passed. All 82
Python and 36 JavaScript tests then passed against the clean source in a Linux
container with networking disabled and source mounted read-only. The pinned
`Dockerfile.tests` provides Python plus Node for the cross-language ZIP check;
Node is not required to run the core product.

Public-domain verification covers actual TLS, exact-origin/consent guards, static
asset hashes, sample ZIP import, independent HTML output, HTTP-to-HTTPS and www
redirects. Existing VPS workloads and the five call records are preserved.

## What is not established

- Representative customer demand, measured time savings or adoption.
- General reconstruction quality across unseen SaaS exports/workflows.
- A controlled cross-model comparison or image ablation.
- Current direct Meta API, Fireworks or hosted Modal operation.
- Unlimited new-input AI access for judges: shared trial is exhausted.
- Recipient acknowledgment, external notification or permission restoration.

The MIT source and synthetic examples support independent review. Private provider
credentials, billing records, customer/account data and machine auth files are
not part of the public source candidate.
